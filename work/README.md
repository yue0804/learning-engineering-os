# work/：原创练习与项目代码

只放**自己写的**代码。上游示例、抄写件、未改动的模板不进入本目录。

## 命名

课程代号-主题-序号，例如：

- ms-2020-shell-01/（Missing Semester 2020，shell 主题，第 1 个练习）
- ha-array-01/（Hello 算法，数组主题）
- gt-func-01/（GoogleTest，函数阶段）

## 每个练习目录建议包含

| 文件 | 作用 |
|---|---|
| 代码 | 本人实现 |
| README.md | 任务来源、我的思路、遇到的困难、与上游示例的差异 |
| run.log 或输出文件 | 真实运行结果（可另存 records/ 并在此引用） |

## 判定

代码能跑不等于已掌握。掌握状态写 PROGRESS.md，由玥本人确认。
