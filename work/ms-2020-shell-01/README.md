## 验收标准（能做到才算过）

1. 不看讲义，说清 `> `、`>>`、`2>`、`|`、`$?` 各自作用，并当场演示；
2. 不用图形界面，在一个会话里完成 5 次目录跳转（`cd`、`..`、`~`、绝对路径）；
3. 用 3 条以上命令接成一条管道，从一份文本里数出目标行数；
4. 把标准输出与标准错误分别落到两个文件，并能解释为何分开。
