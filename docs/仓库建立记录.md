## 结构决策

1. **docs / resources / plan / work / records / corrections 六分**：对应建议文档第 4 节列出的六类内容，一一映射，不设自由堆放区。
2. **引用与产出物理分离**：resources/ 只存链接、版本、章节；work/ 只存本人原创代码。二者不混放，避免「看起来做过」。
3. **STATUS.md 与 PROGRESS.md 分离**：文件生成状态可自动维护，掌握状态只能本人确认。
4. **不设公开 LICENSE**：仓库私有，第三方许可写在 docs/许可与引用.md，不声明本仓库开源。
5. **不内嵌上游全文**：仅在 resources/_vendor/（已忽略）按需拉取。
