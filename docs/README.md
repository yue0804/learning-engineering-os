# docs/：体系文档索引与版本

本目录解决两个问题：**哪些文档是权威**、**当前用的是哪一版**。

## 规则

1. 任何进入体系的文档，必须在 docs/文档索引.md 登记一行：文件、版本、日期、来源、状态。
2. 权威文档以登记表中的「状态=现行」为准；同一文档存在多版本时，旧版标「已被替代」，不得删除。
3. 助手产出物与本人产出物在「来源」列区分：阿序 / 玥 / 外部。
4. 文档正文不在此目录重复维护；本目录只做索引与判定，冲突以原文档为准。
