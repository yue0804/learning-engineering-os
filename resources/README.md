# resources/：上游资源登记

本目录只做一件事：记录**用了哪个上游资源的哪一版哪一章**。

## 规则

1. 每个上游资源一个页面，文件名编号固定（01～08），便于排序与引用。
2. 页面只允许出现：官方地址、服务的学习任务、启用条件、版本锚点、许可、使用登记表。
3. **不粘贴上游正文与示例代码**；需要本地副本时放 resources/_vendor/（已被 .gitignore 排除）。
4. 使用登记表由玥填写：日期、版本或提交号、章节、我的产出、证据位置。
5. 资源状态按建议文档的三层划分：现在可用 / 导航 / 工具候选 / 满足前置后启用。
