# corrections/：错因订正与复测

本目录保存错过、改过、复测通过的完整链条。它是本仓库最有价值的部分之一。

## 单条记录模板

    # 错因记录：<主题>

    - 日期：YYYY-MM-DD
    - 涉及：<练习或文件路径>
    - 现象：<可观察到的错误表现，含原始报错>
    - 根因：<为什么错，指向具体概念>
    - 修正：<改了什么，diff 或代码片段>
    - 复测：<复测命令与结果，指向 records/ 路径>
    - 复测日期：YYYY-MM-DD
    - 是否已掌握：是 / 否（仅玥本人填写）

## 规则

1. 一条记录只写一个错因，不合并。
2. 根因不得写成粗心；必须落到可复述的概念。
3. 未复测的记录保留在册，不得删除；状态标待复测。
